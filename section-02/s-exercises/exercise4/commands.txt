4. `nm s-exercises/exercise4/vault.elf`

5. `objdump -s -j .data s-exercises/exercise4/vault.elf`

Used this to check the win function and saw that it prints the flag.

7. `objdump -d --start-address=0x140001475 --stop-address=0x1400014ef s-exercises/exercise4/vault.elf`  
Checked the menu function and saw how it compares the password.

8. `objdump -s -j .rdata --start-address=0x14000a030 --stop-address=0x14000a080 s-exercises/exercise4/vault.elf`  
This showed the flag and password in the output.
